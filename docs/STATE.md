**Phase 6 polish — Lane-1 RAG indexer (step 3 of 4, partial):** New package `androscan/rag/` (`chunking.py`, `embed.py`, `index.py`, `search.py`) building a per-app SQLite vector index of method-level chunks over the jadx decompiled sources. New `llm`-tier skill `search_decompiled_sources` (query, top_k, package_prefix, file_substr) advertised in the prompt catalog and fail-open. Config: new `rag.embed_provider` / `rag.embed_model` / `rag.top_k_default` in `global_config.yaml` and `Config`, with env overrides `ANDROSCAN_RAG_PROVIDER` / `ANDROSCAN_RAG_MODEL` / `ANDROSCAN_RAG_TOP_K`. New `pyproject` extra `[rag]` (`fastembed`, `numpy`).
